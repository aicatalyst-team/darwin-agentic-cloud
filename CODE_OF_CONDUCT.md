# Code of Conduct

## The rule

**Do not be evil.**

## What that means in practice

- Be respectful. Disagree with ideas, not people.
- No harassment, no discrimination, no personal attacks. Ever.
- Assume good faith. Give people the benefit of the doubt.
- Don't waste people's time. Read before asking, search before opening an issue.
- Credit others' work. Don't claim what isn't yours.
- Don't use this project to harm people. That includes building surveillance tools targeting individuals, weapons of mass harm, or systems designed to deceive at scale.

## Scope

This applies to all project spaces: GitHub issues, PRs, discussions, Discord/Slack if we ever have one, and any event where you represent the project.

## Enforcement

Report violations privately to **135543245+vje013@users.noreply.github.com**.

Maintainers will investigate, respond within a reasonable time, and take action proportional to the violation — up to and including bans from project spaces. We will respect the privacy of reporters.
